XPARROW F1 GP - drop-in engine sounds
Put .wav (or .ogg) files here with these exact names. The game picks them up automatically;
if they are missing it uses the built-in synthesised engine.

Best (4 rpm bands, crossfaded by revs):
  engine_idle.wav    steady idle / pit-lane rev, ~2-4 s seamless loop
  engine_low.wav     steady low revs (~40% of the rev range), seamless loop
  engine_mid.wav     steady mid revs (~70%), seamless loop
  engine_high.wav    steady near-redline, seamless loop
Optional:
  engine_offload.wav off-throttle / overrun crackle loop
  turbo.wav          turbo / MGU-H whine loop (V6 hybrid)
  shift.wav          one gear-change bang
  crash.wav          one impact
  kerb.wav           one kerb rumble hit
Simpler alternative: a single loop named  f1_engine.wav  (pitched by revs).

Tips: mono, 44.1 or 48 kHz, steady RPM (no revving up/down inside a clip), no music or commentary,
cut on zero-crossings so the loop is seamless. Use only sounds you are licensed to use (CC0 / royalty-free / your own recordings).
